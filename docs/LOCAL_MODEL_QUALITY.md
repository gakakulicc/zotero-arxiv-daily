# 本地模型升级与输出质量

默认模型为 Qwen3.5-4B 的 Q5_K_M GGUF（Unsloth 转换，固定 Hugging Face 修订），
输出上限 768 token，上下文 8192，摘要输入预算 4000。配置统一保存在 `config/base.yaml`，
下文保留原来的 Qwen2.5-3B Q4_K_M 回退配置。

## 两次独立调用

1. 摘要：有正文节选时生成 3–4 句总结，重点是贡献、实验支撑与明确的局限；仅摘要时
   用 1–2 句忠实转述，不要求模型补写材料没有给出的实验评价。
2. 机构：只读作者、机构或标题页区域，用专用 JSON schema 提取原文中明确出现的机构。
   没有正文就注明不可提取，不要求模型凭作者姓名猜测。

两个请求复用同一模型实例，但输入、约束、重试和检查点独立。机构失败不会导致摘要重做；
摘要失败也不妨碍尝试机构提取。旧 `combine_llm_requests: true` 不再启用合并调用。

Qwen3.5 通过 GGUF 自带的聊天模板显式关闭思考模式，避免思考内容占用最终回答预算。
这不是隐藏或截掉思考后的半成品；升级时的真实模型验证检查了生成结果中没有思考标签。

## 如何加入“质量优先”

本阶段把质量作为可核对的输出要求，而不给论文制造综合质量分：

- 贡献是否忠实于提供的原文，是否把作者宣称写成了已公认事实。
- 实验是否保留任务、数据集、基线、数值单位，以及仿真/实机的区别。
- 是否明确说明材料中未提供的实验或局限，避免补写不存在的结论。
- 机构是否有明确文字依据，是否误收了参考文献、致谢或正文举例中的机构。
- 是否能连续完成多篇，并在单项失败后保留已完成的信息。

模型升级本身不证明以上指标更好。升级时曾对两个模型运行同一批受控材料，含仅摘要、
长引言加实验/局限、无结构正文三种情况，并检查独立机构提取、思考标签和已知虚构表述。
[历史验证记录](https://github.com/gakakulicc/zotero-arxiv-daily/actions/runs/40466931964)
保留供核对；临时模型验证工作流和脚本已清理。有限样例不能检测所有事实错误，也不是整个
VLA 领域的准确率评测。当前人工端到端验证入口为原有的 Actions → Test。

若以后增加论文层面的评价，建议独立展示实验覆盖范围、泛化验证、开源/复现材料和局限，
并标注“作者报告”或“未找到证据”。先作为阅读参考，不直接改变相关性排序；有用户偏好
标签和多日验证之后，再决定是否加入排序。作者机构、引用量或 GitHub stars 不能单独当作论文质量。

## 配置与回退

`CUSTOM_CONFIG` 显式指定的本地模型仍会覆盖默认值。升级时应同时更新 `repo_id`、
`filename`、`revision`、`enable_thinking` 和 `max_tokens`，不能只改模型名。

回退到原模型时，将以下片段合并到完整的 `CUSTOM_CONFIG`（不是独立完整配置）：

```yaml
llm:
  backend: local
  local:
    repo_id: Qwen/Qwen2.5-3B-Instruct-GGUF
    filename: qwen2.5-3b-instruct-q4_k_m.gguf
    revision: null
    enable_thinking: null
    max_tokens: 512
```

切换模型会重新生成对应摘要，避免复用旧模型的输出。选文嵌入模型和相关性公式不受影响。
